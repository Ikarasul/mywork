# ระบบจัดตารางชีวิตและการเรียน (Life & Study Planner)

เว็บแอปพลิเคชันสำหรับจัดการตารางชีวิต ตารางเรียน งาน/การบ้าน/สอบ และแชทกลุ่ม รองรับการใช้งานทั้งบนคอมพิวเตอร์และมือถือ (Responsive UI)

## เทคโนโลยีที่ใช้
- React + TypeScript + Vite
- Tailwind CSS
- React Router

## วิธีติดตั้งและรันโปรเจกต์

1. ติดตั้งไลบรารีที่จำเป็น:
   ```bash
   npm install
   ```

2. รันเซิร์ฟเวอร์สำหรับพัฒนา (Development Server):
   ```bash
   npm run dev
   ```

3. สร้างไฟล์สำหรับใช้งานจริง (Production Build):
   ```bash
   npm run build
   ```
